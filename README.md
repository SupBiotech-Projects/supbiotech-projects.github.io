# supbiotech-projects.github.io

Official website of the SupBiotech Projects Journal (SBPJ).

## About

SBPJ is a student-led scientific journal showcasing biotechnology projects, scientific reviews, interdisciplinary work, and student perspectives developed at SupBiotech.

The website provides access to journal volumes, PDF archives, and project resources through a modern web interface.
